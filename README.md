# Carlotta-PCB 珂莱塔 PCB艺术板
[![GitHub followers](https://img.shields.io/github/followers/alsunmengy?style=social&label=Follow)](https://github.com/alsunmengy)

> 鸣潮 珂莱塔 艺术PCB | 嘉立创可生产，沉金+彩色丝印+浮雕工艺，开源项目

## 📖 项目简介
这是面向爱好者的二次元艺术PCB装饰板，原型来自游戏《鸣潮》角色 **珂莱塔**。
板卡使用沉金工艺、彩色丝印，搭配阻焊浮雕效果，将角色线稿/泳装插画制作为实体电路板。
**无电气功能，纯艺术装饰板，不能通电。**

包含2套板图：
1. 白底金线线稿版：白色阻焊 + 金色沉金轮廓 + 彩色丝印标识，双人物构图
2. 泳装插画版：彩色丝印全图，沉金勾线，水花角色画面

> ⚠️ 本项目仅用于个人爱好展示，不具备电路功能，请勿接电。

## ✨ 工艺说明（嘉立创 JLCEDA）
|项目|参数|
|---|---|
|板层|2层（纯装饰，无电气网络）|
|表面处理|沉金 (ENIG)，金色线条为沉金露铜|
|阻焊|白色阻焊（线稿版）；常规阻焊（泳装版）|
|丝印|彩色丝印工艺（嘉立创彩色丝印服务）|
|特色工艺|阻焊浮雕（Solder Mask Relief），实现画面凹凸浮雕质感|
|外形|圆角矩形，板框倒角|
|生产来源|嘉立创EDA工程输出，可直接投板|

> 提示：彩色丝印、浮雕属于特殊工艺，下单时需要在嘉立创后台手动勾选对应工艺选项，会产生额外工艺费用。



## 🛠️ 如何生产
1. 下载Gerber文件
2. 参数设置：
   - 层数：2层板
   - 表面工艺：沉金
   - 阻焊颜色：白
   - 开启【彩色丝印】
3. 核对预览图片无误后提交订单

> 重要提醒：
> 1. 浮雕高度、丝印色彩会受PCB工厂工艺限制，实物与效果图会存在轻微色差。
> 2. 板子没有任何电路，仅作为摆件收藏。
